04

Service ที่หน้าบ้านต้องขอจากทีมหลังบ้าน

ไม่ต้องออกแบบ DB แล้ว แต่ต้องเคาะ 8 endpoint นี้กับพี่ที่ทำ service เพื่อให้ UI แต่ละจอมีข้อมูลครบ — คอลัมน์ขวาคือ field ที่จอนั้นต้องใช้จริง

ใช้ที่จอServiceต้องได้ field
S1 ค้นหาแมทGET /materials/searchmat_no, ชื่อ, หมวด, ราคาปกติ, ราคาสมาชิก, รูป, ยกกลับได้/ต้องส่ง, ต้องติดตั้ง
S1 เช็คสต็อกGET /materials/{mat}/stockรายสาขา/คลัง: on_hand, reserved, ATP date, ชื่อ location
S2 ค้นหาลูกค้าGET /customers/search?q=cust_no, ชื่อ, tier, เบอร์, อีเมล, ที่อยู่ default, มีตะกร้าค้างกี่ชิ้น
S2 รวมตะกร้าPOST /carts/{id}/mergeรายการหลัง merge + added_by (customer/sales) ต่อบรรทัด
S3 โปรโมชั่นPOST /promotions/evaluateโปรที่ใช้ได้ + ส่วนลดเป็นบาท + เงื่อนไขที่ยังไม่ครบ + ใช้ร่วมกันได้ไหม + โควตาส่วนลดพนักงาน
S4 ค่าส่ง + คิวPOST /delivery/quoteค่าขนส่งตามเขต, slot ว่าง (วัน + รอบ + จำนวนคิวเหลือ), แยกกลุ่มยกกลับ/ส่ง/ติดตั้ง
S5 PresoPOST/GET /presospreso_no, สถานะร่าง, ลูกค้า, บรรทัดสินค้า, โปรที่เลือก, slot ที่เลือก, ยอดรวม
S6 QuotationPOST /quotations · POST /payments · GET /quotations/{no}quotation_no, วันยืนราคา, PDF url, payment status, sap_so_no ที่ส่งกลับมาหลังจ่ายเงิน
2 เรื่องที่ต้องถามพี่หลังบ้านให้ชัด

1. การคำนวณโปร/ส่วนลด คิดที่ฝั่งไหน — ถ้าคิดที่ SAP หน้าบ้านต้องเรียก evaluate ทุกครั้งที่ตะกร้าเปลี่ยน (ต้องรู้ response time)
2. Quotation ถูกสร้างที่ระบบเรา แล้ว sync ไป SAP หรือสร้างที่ SAP ตั้งแต่แรก — มีผลกับว่าเลข QT ใครออก และแก้ไขได้แค่ไหนหลังสร้าง

05

สรุป + สิ่งที่ต้องเคาะต่อ

อธิบาย 3 บรรทัด

เซลล์ทำงานเป็นเส้นตรง: หาของ → เช็คว่ามีจริง → ใส่ตะกร้า → ผูกลูกค้า → เช็คโปรกับคิวส่ง → เซฟ Preso → ออก Quotation → พาไปจ่ายเงิน จบที่หน้าบ้าน ที่เหลือ SAP รับไป

ยังต้องเคาะ
· Preso 1 ใบ = 1 ลูกค้าเท่านั้น หรือแยกหลายใบต่อลูกค้าได้ · Quotation แก้ไขได้หลังสร้างไหม หรือต้อง cancel + ออกใหม่ · โควตาส่วนลดเซลล์กี่ % และใครอนุมัติเมื่อเกิน · ลูกค้าใหม่ walk-in ต้องมี cust_no ใน SAP ก่อนออก Quotation ไหม · เซลล์เพิ่มของในตะกร้าลูกค้าได้เลย หรือต้องให้ลูกค้ากดยืนยัน (ตอนนี้: เพิ่มได้เลย ลูกค้าลบได้)
ขั้นถัดไป: ทำ prototype กดได้ตามเส้น 9 สเต็ปนี้ (S1→S6) เอาไปให้เซลล์ลองจับบนแท็บเล็ตจริง ก่อนเริ่มต่อ service
